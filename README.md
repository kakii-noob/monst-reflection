# monst-reflection

画像上の反射ガイドに、1024方向モードと貫通ルートの条件付き検索を追加しています。
ビルド作業なしで、リポジトリ直下をGitHub Pagesから配信できます。

## 使い方

1. スクリーンショットを読み込み、「配置・ルート検索」を開きます。
2. 「始点を置く」で手番のキャラ中心をタップします。
3. ボス・本・敵・弱点・地雷を画像上に配置します。「本＋内部弱点」は2つの判定を作ります。
4. 「設定に戻る」で対象の名前・横半径・縦半径を調整します。目玉などは「接触を避ける」にできます。
5. 「順番条件に追加」で順序を指定するか、「ボス → 地雷2個で本 → 内部弱点」を設定します。必要地雷数は接触直前の数です。
6. 探索距離・反射上限・ずれの幅を指定して検索します。候補を押すと、その角度と予測線を表示し、音声コントロール用ファイルにも使えます。

配置中は設定パネルが閉じます。画像上で連続して配置・移動し、「設定に戻る」で編集を続けてください。
対象や条件・始点が変わると古い検索結果は破棄されます。画像を変更すると配置と条件をリセットします。

## 角度と検索の前提

- 1024方向モードは、1周を1024等分した0.3515625°刻み・最寄り方向への丸めを仮定します。ゲーム実機の仕様を確認したものではありません。従来の自由角度にも切り替えられます。
- 検索は1024方向を対象に、指定した条件を順に達成する経路を探します。最後の条件まで、避ける設定の対象に触れる経路を除外します。
- 判定は手動で配置した円・楕円にキャラの接触半径を加えた近似です。地雷は最大4個まで持ち、敵本体・弱点への接触時に1個ずつ消費します。同じ地雷は拾い直さず、同じ判定の内側にいる間も重複接触にしません。
- 誤差検査は、前後の指定段数の角度と、始点の中心・上下左右・斜めの9位置の組み合わせで行います。成立数が多い候補を優先し、同率なら移動距離を優先します。成立数は実機での成功確率ではありません。
- 貫通を想定しており、敵との反射・減速・ワープ・速度・与ダメージは計算しません。探索距離は速度から推定せず、自分で上限を指定します。
- 音声ファイルの座標への変換には従来の近似が残ります。実際の発射角度やiOSでの再生は実機で確認してください。

## 回帰テスト

Node.js 24以降を使用します。計算・既存機能のテストに加え、jsdomで画面の配置・条件・検索・中止の一連の動作を確認します。jsdomはテスト専用で、公開サイトでは使いません。

```sh
npm ci
npm test
```

このテストはゲーム実機での発射角度や、iOSでのジェスチャ再生を保証するものではありません。
